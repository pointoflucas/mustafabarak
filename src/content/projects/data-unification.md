The interesting part of this project wasn't simply moving data. It was deciding when two imperfect records actually described the same thing.

This involved entity resolution techniques, data modeling and building a consistent layer that downstream analytics could trust. The work touched on problems of identity, semantics and uncertainty rather than just pipelines.

Key aspects of the work included:
- Entity resolution and matching algorithms
- Handling uncertain and imperfect data
- Building data models that could be trusted downstream
- Creating a semantic understanding of the data

The output was a unified data layer that analytics teams could build on with confidence.
